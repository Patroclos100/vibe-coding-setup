# SvelteKit Web Stack

Location: `templates/.ai/stacks/sveltekit-web/`

## Mandatory checks
- `pnpm lint`
- `pnpm check`
- `pnpm test:unit`
- `pnpm test:smoke`
- `pnpm build`

## Intended use
Use this stack for browser-based applications where UI behavior, smoke validation, and build success are required.


# Installation

## 1 Clone Repository

git clone <repo>
cd vibecoding-framework

## 2 Run Setup

./scripts/setup-tools.sh

This installs:

- OpenCode
- Templates
- Commands
- AI framework files
- Global configuration

## 3 Verify Setup

~/tools/check-current-setup.sh

## 4 Connect Copilot

Start OpenCode:

opencode

Then run:

/connect

Select GitHub Copilot.

# Project Memory Guide

## 1. Zweck

Projektwissen soll im Repository auffindbar bleiben und nicht in flüchtigen Chatverläufen verschwinden.

## 2. Standarddateien

- `.ai/context/project-overview.md`
- `.ai/context/current-status.md`
- `.ai/context/open-questions.md`
- `.ai/context/known-issues.md`
- `.ai/context/next-step.md`

## 3. Pflegeprinzipien

Gut:

- kurz
- konkret
- aktuell
- mit echten Entscheidungen und offenen Punkten

Schlecht:

- lange Fließtexte ohne Arbeitsnutzen
- Chat-Zusammenfassungen ohne Priorisierung
- veraltete Statusinformationen

## 4. Mindestpflege

Nach relevanten Änderungen mindestens aktualisieren:

- aktueller Status
- offene Fragen
- nächster sinnvoller Schritt

## 5. Nutzen

Die Memory-Struktur hilft bei:

- Wiedereinstieg nach Unterbrechung
- Übergabe an Dritte
- sauberer Planbarkeit kleiner nächster Schritte
- reproduzierbarer AI-Arbeit

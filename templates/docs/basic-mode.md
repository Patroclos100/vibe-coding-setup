# Basic Mode

Dieses Projekt wurde aus dem VibeCoding AI Factory Framework erzeugt.

## Nutze zuerst nur diesen Ablauf

```text
/intake -> /plan-feature -> /build-small -> /fix -> /review-release
```

## Einfache Regeln

- immer nur ein kleines Inkrement
- keine großen Umbauten beim ersten Durchlauf
- nicht direkt frei drauflos prompten
- bei Unklarheit zuerst `/status`

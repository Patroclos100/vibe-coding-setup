# Review Checklist

## Code and structure

- Build passes
- TypeScript is clean or known issues are documented
- No unnecessary dependencies were added
- No unrelated files were changed without reason
- File placement follows architecture rules

## UX and UI

- Primary flow still works
- Empty, loading or error states were considered where relevant
- Labels and messages are understandable
- No obvious visual regression in touched screens

## Scope and maintainability

- Change size matches the chosen workflow
- No hidden complexity was introduced
- Open issues are written to `.ai/context/*` if not resolved

## Handover

- `current-status.md` updated when needed
- `next-step.md` updated when needed

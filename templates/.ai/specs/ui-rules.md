# UI Rules

1. Optimize for clarity over visual novelty.
2. Prefer simple layout, clear labels, predictable actions.
3. Every primary user action must have a visible success or error state.
4. Forms must validate obvious bad input.
5. Responsive behavior must remain usable on common viewport sizes.
6. Accessibility baseline:
   - semantic elements
   - keyboard reachable controls
   - visible focus states
   - descriptive labels
7. Avoid hidden complexity in UI components.

# Product Specification

## Requested Outcome
Summarize the requested business outcome.

## Normalized Scope
Translate the request into explicit software behavior.

## Current Increment
Define the smallest deliverable increment to implement now.

## Acceptance Criteria
List only criteria for the current increment.

## Assumptions
List assumptions made due to incomplete input.

## Open Risks
List ambiguity, hidden dependencies, edge cases, and delivery risks.

## Non-Goals
List what must not be implemented in this increment.

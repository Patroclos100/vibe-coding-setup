# Feature Workflow

1. Normalize request into product spec.
2. Validate architecture fit.
3. Review dependency needs.
4. Implement smallest complete increment.
5. Generate tests for current scope.
6. Run relevant checks.
7. If checks fail, invoke Debug Agent.
8. If structural issue is proven, invoke Refactoring Agent.
9. Re-run checks.
10. Run release checklist for the increment.

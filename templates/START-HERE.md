# Start Here

Du musst nicht das ganze Framework verstehen, um erfolgreich zu starten.

## Erster sicherer Ablauf

1. `requirements.md` grob ausfüllen
2. `docs/basic-mode.md` lesen
3. `AGENTS.md` kurz überfliegen
4. In OpenCode nur diesen Pfad nutzen:

```text
/intake -> /plan-feature -> /build-small -> /fix -> /review-release
```

## Was du am Anfang ignorieren darfst

- große Refactorings
- `/build-large`
- Runtime-Interna
- Factory-CLI
- Modul-Registry

## Wenn etwas unklar ist

- `docs/troubleshooting.md`
- `/status`
